# Get In Tune Hub

Marlys's app for running Get In Tune: email, calendar, tasks, clients and a daily brief in one place, with Claude
built in.

It starts as a copy of Keystone (Hunter's app for Forefront Building + Restoration) and is being turned into
Marlys's own app step by step with Claude Code. See **PLAN.md** for the plan and what's done, and **CLAUDE.md** for
how it's built and the house rules.
